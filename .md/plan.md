# 一、组件掌握【阶段验证清单】（打勾版）

> 用来解决：
> **“我到底算不算真的学会了？”**

你不用等 7 天，**只要每个阶段能打勾，就继续下一个组件**。

---

## 🟦 阶段 1：理解关（当天完成，60–90 分钟）

> 目标：**知道它是干嘛的、放哪、什么时候用**

**必须全部打勾：**

* ⬜ 我能用一句话说清这个组件解决什么问题
* ⬜ 我知道它在 Agent / 工作流中的位置
* ⬜ 我知道「不用它」会带来什么问题
* ⬜ 我能看懂一个最小示例，不需要记 API
* ⬜ 我能判断：这是**核心组件**还是**辅助组件**

👉 没打完 ❌
👉 打完 ✅ → **立刻进入下一个组件**

---

## 🟨 阶段 2：控制关（1–3 天内任意时间，30 分钟）

> 目标：**它不再是“魔法”，而是“工具”**

**必须全部打勾：**

* ⬜ 我能用 **纯 Python（if / dict / list）** 模拟它 60% 的功能
* ⬜ 我知道它最容易被误用的地方
* ⬜ 我知道什么时候**不该用它**
* ⬜ 我知道它抢的是谁的控制权（LLM / 流程 / 状态）

👉 如果你只能“会用 API”，但不会低配实现
→ ❌ 还没过关

---

## 🟩 阶段 3：恢复关（第 5–7 天，10–15 分钟）

> 目标：**验证有没有“假掌握”**

**不看文档、不跑代码，只回答：**

* ⬜ 核心职责？
* ⬜ 典型使用场景？
* ⬜ 在大型项目中一般在哪一层？
* ⬜ 不用它的替代方案？
* ⬜ 和 LangGraph / Agent 的关系？

👉 顺畅回答 = ✅ 真掌握
👉 卡壳 = ❌ 回炉 15 分钟即可

# 二、【10 分钟组件掌握度自测表】（极狠，但极准）

> 你任何一天都可以用它
> **专门防“我好像懂了”**

---

## 自测题（不许查资料）

请你现在假设：**正在自测某个组件**

### Q1（定位）

> 这个组件在 Agent 系统里，是在解决哪一类不确定性？

* ⬜ 语义不确定
* ⬜ 流程不确定
* ⬜ 状态不确定
* ⬜ 权限不确定
* ⬜ 能力不确定

👉 说不出来 = ❌

---

### Q2（替代）

> 不用这个组件，你会怎么写一个“丑但能跑”的版本？

👉 如果你脑子里没有 if / dict / list
= ❌

---

### Q3（滥用）

> 这个组件最常见的**错误使用方式**是什么？

👉 这是区分“会用”和“理解”的关键题

---

### Q4（边界）

> 哪一类逻辑**绝对不该**交给这个组件？

👉 能答 = 工程思维已建立

---

### Q5（迁移）

> 如果从 LangChain 换到 LangGraph / AutoGen / 自写框架，这个组件的“思想”还在吗？

👉 能抽象出来 = ✅ 高阶掌握

---

### 自测评分标准

* 5 题全答顺：**A（已掌握）**
* 3–4 题顺：**B（可用，但需回访）**
* ≤2 题：**C（只是用过）**
