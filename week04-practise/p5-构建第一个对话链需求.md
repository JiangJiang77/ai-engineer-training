# p5-构建第一个对话链 需求

## 1. 目标
通过本练习，掌握 LangChain 中构建对话链的核心要素以及 LCEL (LangChain Expression Language) 的基本用法。

## 2. 核心内容
### 2.1 环境准备
- 安装关键库：`langchain`, `langserve`, `langsmith`, `langgraph`, `langchain-deepseek`, `langchain_community`, `python-dotenv` 等。

### 2.2 构建对话链的三大要素
- **语言模型 (Language Models)**:
    - 区分 LLM (字符串输入输出) 与 ChatModel (Message 列表输入输出)。
    - 掌握不同角色的消息类型：`HumanMessage`, `AIMessage`, `SystemMessage` 等。
- **提示词模板 (Prompt Templates)**:
    - 使用 `PromptTemplate` 和 `ChatPromptTemplate`。
    - 支持变量注入、多变量格式化及 Jinja2 逻辑。
- **输出解析器 (Output Parsers)**:
    - 将模型输出转换为结构化数据（如 JSON, List, Pydantic 对象）。
    - 常用解析器：`PydanticOutputParser`, `CommaSeparatedListOutputParser`, `StructuredOutputParser`。

### 2.3 LCEL (LangChain Expression Language)
- 使用管道操作符 `|` 将 Prompt、LLM 和 Output Parser 连接成链。
- 掌握 `chain.invoke()` 的调用方式。

## 3. LCEL 的优势
- 语法简洁直观。
- 自动处理组件间的类型推断与转换。
- 原生支持流式处理、并行执行和结果缓存。
- 统一的 `Runnable` 接口。
